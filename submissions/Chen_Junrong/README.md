# Chen_Junrong · DermaMNIST 七分类

## 结论

- `submission.csv`：2005 行 `id,label`，已用 `python score.py --check submission.csv` 通过格式检查。
- 验证集（1003 张，未参与训练）：**accuracy 0.7418 · balanced accuracy 0.5852 · macro-F1 0.5490**。
- 训练 + 预测全程 CPU，约 16 分钟（4 个模型，每个 26 轮 × 7.5 秒）；单个模型约 3.5 分钟，已经够跑通一版。

## 我们怎么做的

1. **模型**：自己写的 14 万参数小 CNN（两层 3×3 卷积 → 池化 → 两层 → 池化 → 一层 → 全局平均池化 → 全连接）。
   28×28 的图不需要大网络，也不用预训练权重，`torchvision` 都没装，读图直接用 PIL。
2. **对付不平衡**：`train/` 里黑素细胞痣占 67%，皮肤纤维瘤只占 1.1%。损失函数用类别权重
   `w ∝ (N/n_c)^0.5`（开方是为了压住多数类，但不至于把多数类的 recall 压死），另加 label smoothing 0.05。
3. **数据增强**：左右翻、上下翻、90° 旋转、反射填充后随机平移 2 像素以内。皮肤镜图没有固定朝向，这类增强完全合法。
4. **训练**：AdamW，OneCycle 学习率，26 轮，batch 128，每轮后在 `val/` 上算三个指标，按 balanced accuracy 存最佳轮次。
5. **预测**：四重 TTA（原图 / 左右翻 / 上下翻 / 旋转 180°）平均概率，再对 4 个不同随机种子的模型等权平均。
6. **指标口径**：直接 import 数据包里的 `score.py` 用它的 `score()` 和 `macro_f1()`，保证和官方打分完全一致。

## 试过但没用的：类别先验修正

因为评分方式现场才揭晓，我们把「按训练集先验做温度修正 `p / prior^α`」扫了一遍（4 模型平均，val）：

| α | accuracy | balanced accuracy | macro-F1 |
|---|---|---|---|
| 0（最终采用） | **0.7418** | 0.5852 | **0.5490** |
| 0.1 | 0.7109 | 0.5905 | 0.5263 |
| 0.2 | 0.6959 | 0.6134 | 0.5190 |
| 0.3 | 0.6640 | **0.6145** | 0.4942 |

修正确实能把 balanced accuracy 抬到 0.61，但 accuracy 和 macro-F1 一起掉，只有 balanced accuracy 一项受益。
三种常见评分里 α=0 占两项，所以没有采用。

另一个没采用的：在 val 上挑「表现最好的单个模型」（seed3 的 macro-F1 0.5584 略高于平均的 0.5490）。
1003 张验证集上 0.01 的差距是噪声，从 4 个模型里挑最高的等于对验证集过拟合，所以仍然用全部 4 个平均（见 `average.py --select` 的提示）。

## 怎么复现

```bash
# 数据解压到与本文件夹同级的 DermaMNIST/（内含 train/ val/ test/）
python train_cnn.py --epochs 26 --width 32 --seed 1 --save-probs --out work/sub_s1.csv
# 换成 --seed 2 3 4 各跑一次
python average.py work          # 等权平均 4 个模型 -> submission.csv
python score.py --check submission.csv
```

`train_cnn.py` 会自动在上层目录找 `DermaMNIST/`，并把权重和中间概率写到 `work/`（不随提交上传）。
想只重新预测：`python train_cnn.py --predict-only`。
