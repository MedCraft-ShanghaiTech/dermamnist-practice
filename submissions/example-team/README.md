# example-team（示例，不用改它）

这是一个示例文件夹。你们自己的文件夹照着它建：`submissions/队名/`，文件夹名就是队名，榜上只显示它。里面放三样：

- `submission.csv`：测试集预测，格式和数据包里的 `sample_submission.csv` 一样；
- 你们的代码，比如 `train.py`；
- `README.md`：就像这个文件，写几句"我们怎么做的"，比如：

> 我们用一个小卷积网络，训练时给图少的类别加了权重，在 CPU 上训练了 5 分钟，用验证集挑了最好的一轮。

数据文件夹和模型权重（`.pt`、`.pth` 等）不要放进来。
