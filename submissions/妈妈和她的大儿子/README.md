# 妈妈和她的大儿子

DermaMNIST 皮肤镜 7 分类 · 现场实践提交。

模型名：自建小 CNN（3 个卷积块）+ 类别加权 + 4 视图 TTA + 3 种子集成

## 我们怎么做的

1. **模型**：自己搭的小 CNN（3 个卷积块，通道 32/64/128，每块卷积×2 + BN + ReLU + 2×2 池化，全局平均池化后接全连接），大约 40 万参数，在 CPU 上训练。
2. **数据增强**：随机水平/垂直翻转、随机旋转 ±15°、缩放 0.9–1.1、平移 ±12%、亮度/对比度抖动。
3. **应对类别不平衡**：交叉熵按类别频率的 −0.5 次方加权（黑素细胞痣 4693 张、皮肤纤维瘤只有 80 张），另加 0.05 的 label smoothing。
4. **训练**：AdamW（lr 2e-3）+ OneCycle 调度，35 个 epoch，batch 128；每个 epoch 在 `val/` 上算 balanced accuracy，保留最好的那个。
5. **推理**：4 视图 TTA（原图 / 水平翻转 / 垂直翻转 / 双向翻转）取平均；3 个随机种子（1/2/3）的概率再平均。

这个方案没用到测试集，也没有外部数据，只用了题目给的 `train/` 与 `val/`。

## 验证集结果（1003 张，未参与训练）

| 指标 | 单模型 | 3 种子 + TTA |
|---|---|---|
| accuracy | 0.7268 | **0.7288** |
| balanced accuracy | 0.6285 | **0.6397** |
| macro-F1 | 0.5713 | **0.5822** |

每类 recall：黑素细胞痣 0.79、血管病变 0.79、基底细胞癌 0.69、光化性角化 0.67、黑色素瘤 0.57、良性角化样 0.56、皮肤纤维瘤 0.42。

集成主要改善了少数类；黑色素瘤召回反而略降（常与黑素细胞痣混淆），这是 28×28 分辨率下的主要瓶颈。

## 文件

- `submission.csv`：测试集 2005 行预测（`id,label`）
- `train.py`：完整训练 + 推理脚本

## 复现

```bash
pip install numpy pandas pillow torch
python train.py --data DermaMNIST --out out --epochs 35 --seeds 1,2,3
```

`--data` 指向解压出的 `DermaMNIST/` 文件夹，产物是 `out/submission.csv` 和 `out/val_pred.csv`。
